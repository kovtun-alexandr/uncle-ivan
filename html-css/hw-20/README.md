# Interactive Card Details Form — hw-20

Short description: Implementation of an interactive card details form.

## Overview

This project implements an interactive credit-card details form with the following features:

- Live update of the card preview while typing
- Validation for card number, expiry date, and CVC with error messages
- A completed state shown after successful submission and the ability to reset the form
- Responsive, mobile-first layout
