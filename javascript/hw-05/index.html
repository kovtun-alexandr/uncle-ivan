Домашнє завдання: Об'єкти та методи масивів у контексті Магазину Електроніки

Вступна частина: Дані для роботи

Для виконання завдань використовуй наступний масив об'єктів (інвентар магазину): 


    const inventory = [
        { id: 1, name: "Laptop Pro 16", price: 45000, category: "Laptops", stock: 5 },
        { id: 2, name: "Wireless Mouse", price: 1200, category: "Accessories", stock: 15 },
        { id: 3, name: "Gaming Monitor", price: 12000, category: "Monitors", stock: 0 },
        { id: 4, name: "USB-C Cable", price: 450, category: "Accessories", stock: 50 },
        { id: 5, name: "Mechanical Keyboard", price: 3500, category: "Accessories", stock: 8 },
        { id: 6, name: "Smartphone X", price: 28000, category: "Phones", stock: 3 },
    ];

Фільтрація та пошук — `getAvailableAccessories`

Адміністратор хоче бачити список аксесуарів, які зараз є в наявності, щоб сформувати звіт для відділу закупівель.

Картина задачі словами:

Потрібно взяти весь список товарів і відсіяти лише ті, що належать до категорії `"Accessories"` ТА мають залишок на складі більше нуля.

Запитання для роздумів:

  • Який метод масиву найкраще підходить для створення підмножини даних на основі умови?
  • Як об'єднати дві умови (категорія і наявність) в одному колбеку?
  • Що поверне метод `filter`, якщо жоден товар не підійде під умови?

Завдання:

  • Створіть змінну `availableAccessories`.
  • Використовуючи метод `filter`, виберіть з масиву `inventory` товари, у яких `category === "Accessories"` і `stock > 0`.
  • Виведіть результат у консоль.

Методи: `filter()`, логічне `&&`

Глобальний розпродаж — `applyDiscount`

Магазин оголошує акцію: знижка 15% на всі товари дорожче 5000 грн. Потрібно підготувати дані для нових цінників.

Картина задачі словами:

Ми створюємо новий список (масив рядків). Для кожного товару перевіряємо ціну: якщо вона висока — рахуємо нову ціну зі знижкою 15%. Результатом має бути масив текстових повідомлень, готових до друку.

Запитання для роздумів:

  • Чи змінює метод `map` оригінальний масив `inventory`? Чому це важливо?
  • Як обчислити ціну зі знижкою 15%? (Підказка: помножити на 0.85).
  • Як за допомогою template literals вивести рядок формату `"Товар: ціна грн"`?

Завдання:

  • Створіть масив `salePrices` за допомогою методу `map`.
  • Якщо `price > 5000`, нова ціна = `price * 0.85`, інакше ціна залишається без змін.
  • Результатом `map` має бути рядок: `` `${item.name} - нова ціна: ${finalPrice} грн` ``.
  • Виведіть отриманий масив у консоль.

Методи: `map()`, тернарний оператор або `if/else`, template literals

Аудит складу — `checkStockStatus`

Керівник хоче швидко дізнатись: чи є у нас дефіцитні позиції та чи не закралася помилка в ціни.

Картина задачі словами:

Нам не потрібні всі товари, лише відповіді "так/ні". Чи є хоч один товар, якого 0 на складі? Чи всі товари мають коректну ціну (більше 0)? Також потрібно знайти конкретний товар за його ID для перевірки.

Запитання для роздумів:

  • Яка різниця між `some` та `every`? Що вони повертають?
  • Що поверне `find`, якщо товару з таким `id` не існує?
  • Чи зупиняє `some` перебір масиву, як тільки знайде першу відповідність?

Завдання:

  • За допомогою `some` перевірте, чи є в магазині хоча б один товар з `stock === 0`. Виведіть результат (`true/false`).
  • За допомогою `every` перевірте, чи всі товари коштують більше `100` грн.
  • За допомогою `find` знайдіть об'єкт товару, у якого `id === 3`.
  • Виведіть результат у консоль.

Методи: `some()`, `every()`, `find()`

Фінансова аналітика — `calculateTotalValue`

Потрібно порахувати загальну вартість усього товару, який зараз лежить на складі, для страхової компанії.

Картина задачі словами:

Для кожного товару ми беремо його ціну і множимо на кількість (stock). Всі ці суми треба додати одну до одної, щоб отримати одне фінальне число — капіталізацію складу.

Запитання для роздумів:

  • Яке початкове значення акумулятора (`initialValue`) варто передати в `reduce` для підрахунку суми?
  • Що буде, якщо забути написати `return` всередині колбеку `reduce`?
  • Як звернутися до властивостей об'єкта всередині ітерації `reduce`?

Завдання:

  • Створіть змінну `totalInventoryValue`.
  • Використовуйте `reduce`, щоб пройти по масиву `inventory`.
  • На кожній ітерації додавайте до акумулятора результат множення `item.price * item.stock`.
  • Виведіть фінальну суму у консоль з повідомленням: `"Загальна вартість складу: ... грн"`.

Методи: `reduce()`

Об'єкт менеджер — `storeManager`

Створіть об'єкт, який буде "керувати" нашим магазином.

Картина задачі словами:

Замість того, щоб просто тримати масив десь у коді, ми створимо об'єкт `storeManager`. У нього буде властивість `items` (наш масив) і методи для роботи з ним. Це допоможе нам групувати логіку в одному місці.

Запитання для роздумів:

  • Як отримати доступ до властивості `items` зсередини методу об'єкта за допомогою `this`?
  • Чому в методах об'єкта краще використовувати звичайні функції, а не стрілкові (якщо ми плануємо використовувати `this`)?
  • Як метод `push` змінює масив `items`?

Завдання:

  • Оголосіть об'єкт `storeManager`.
  • Додайте йому властивість `items`, куди скопіюйте масив `inventory`.
  • Додайте метод `updateStock(productId, newStock)`:
    • Метод має знайти товар за `id` у масиві `this.items` і змінити його `stock` на `newStock`.
    • Якщо товар знайдено, вивести: `"Запас товару [назва] оновлено до [кількість]"`.
  • Додайте метод `printInventory()`:
    • Він має вивести в консоль назву та кількість кожного товару у зручному вигляді (використовуй `forEach`).
  • Перевірте роботу: викличте `storeManager.updateStock(1, 10)` та `storeManager.printInventory()`.

Методи: `this`, `find()`, `forEach()`, об'єкти
