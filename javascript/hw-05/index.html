Домашнє завдання: Функції та типи даних в контексті онлайн-кінотеатру

Форматування тривалості фільму — `formatDuration`

На сторінці фільму поруч з постером відображається його тривалість. У базі даних вона зберігається у хвилинах, але користувачу зручніше бачити години та хвилини.

Картина задачі словами:

Уявіть: у базі записано `135`. Але на сайті має з'явитись `"2 год 15 хв"`. Функція отримує число хвилин, розбиває його на години та залишок хвилин і збирає зрозумілий для користувача рядок.

Запитання для роздумів:

  • Як з числа `135` отримати кількість повних годин? Яка математична операція тут потрібна?
  • Як дізнатись, скільки хвилин "залишилось" після відбирання годин? Який оператор повертає остачу від ділення?
  • Якщо хвилин `0` — що виводити: `"2 год"` чи `"2 год 00 хв"`? Вибери один варіант і обґрунтуй.
  • Якщо фільм триває менше 60 хвилин — чи потрібно виводити `"0 год 45 хв"` чи просто `"45 хв"`?
  • Де у функції доречно використати template literal, а де — звичайне `if/else`?

Завдання:

  • Оголоси функцію `formatDuration(minutes)` через **function declaration**.
  • Всередині функції:
    • Обчисли кількість повних годин (`Math.floor`) та хвилин, що залишились (`%`).
    • Якщо годин `0` — повертай лише `"45 хв"` (тільки хвилини).
    • В іншому випадку — повертай `"2 год 15 хв"` (і те, і те).
  • Виклич функцію з кількома значеннями і виведи результат у `console.log`:
    • `formatDuration(135)` → `"2 год 15 хв"`
    • `formatDuration(60)` → `"1 год 00 хв"`
    • `formatDuration(45)` → `"45 хв"`

Оператори та методи: `/`, `%`, `Math.floor()`, `if/else`, template literals, `return`

Перевірка URL-назви фільму — `validateSlug`

Коли адміністратор додає новий фільм на сайт, він вводить його URL-назву (slug). Система перевіряє, чи назва відповідає вимогам, і повідомляє про помилку або підтверджує прийняття.

Картина задачі словами:

На сайтах кіно URL фільму виглядає як `kinosite.com/films/the-dark-knight`. Назва між `/` — це slug. Вона не може бути порожньою, задовгою або містити пробіли. Функція отримує рядок, перевіряє три умови і повертає відповідне повідомлення.

Запитання для роздумів:

  • Як перевірити, що рядок після очищення від пробілів по краях насправді порожній? Яке значення має `length` порожнього рядка?
  • Чи важливий порядок перевірок? Що буде, якщо перевірити довжину _до_ перевірки на порожнечу?
  • Як привести slug до нижнього регістру перед поверненням? Який метод рядка це робить?
  • Оператор `&&` чи `||` — який з них підходить для умови "рядок НЕ порожній І НЕ задовгий"?

Завдання:

  • Оголоси функцію `validateSlug(title)` через function declaration
  • Перед перевірками обріжи зайві пробіли по краях (`trim()`).
  • Логіка з `if / else if / else`:
    1. Якщо очищений рядок має `length === 0` — повертай: `"Помилка: назва порожня"`.
    2. Інакше якщо `length > 50` — повертай: `"Помилка: назва задовга"`.
    3. Інакше якщо містить пробіл (`includes(" ")`) — повертай: `"Помилка: пробіли заборонені, використай дефіс"`.
    4. Інакше — повертай: `` `Slug прийнято: ${назва у нижньому регістрі}` ``.
  • Виклич функцію і виведи результат у `console.log`:
    • `validateSlug(" ")` → `"Помилка: назва порожня"`
    • `validateSlug("the dark knight")` → `"Помилка: пробіли заборонені, використай дефіс"`
    • `validateSlug("The-Dark-Knight")` → `"Slug прийнято: the-dark-knight"`

Методи та властивості: `trim()`, `length`, `includes()`, `toLowerCase()`, `if/else if/else`, template literals, `return`

Розрахунок ціни квитка — `calcTicketPrice`

На сторінці каси онлайн-кінотеатру є система знижок. Ціна квитка залежить від віку глядача та наявності студентського квитка.

Картина задачі словами:

У реальних кінотеатрах дітям, пенсіонерам і студентам — знижки. Функція отримує базову ціну, вік і булеве значення про студентський квиток, застосовує відповідне правило і виводить результат з поясненням.

Запитання для роздумів:

  • Скільки відсотків від `basePrice` — це 30% знижка? Як це обчислити математично?
  • Як оператор `??` може допомогти задати ціну за замовчуванням, якщо `basePrice` не передано?
  • Що станеться, якщо `hasStudentCard` передати як `false`, а `age` — 20? Яке правило спрацює?
  • Чи можна студенту-пенсіонеру (якщо б таке було) отримати одночасно дві знижки? Як це регулює `if/else if`?
  • Як перевірити булевий параметр — `if (hasStudentCard === true)` чи `if (hasStudentCard)`? Яка різниця?

Завдання:

  • Оголоси функцію `calcTicketPrice(basePrice, age, hasStudentCard)` через function declaration.
  • Якщо `basePrice` не передано — використай значення `200` за допомогою оператора `??`.
  • Логіка `if / else if / else`:
    1. Якщо `age < 7` — квиток безкоштовний (`0 грн`), знижка `"дитяча"`.
    2. Інакше якщо `age >= 65` — знижка 50%.
    3. Інакше якщо `hasStudentCard` — знижка 30%.
    4. Інакше — повна ціна, знижка `"відсутня"`.
  • Виводь у консоль: `` `Квиток: ${finalPrice} грн (знижка: ${discountName})` ``
  • Виклич функцію кілька разів:
    • `calcTicketPrice(200, 5, false)` → `"Квиток: 0 грн (знижка: дитяча)"`
    • `calcTicketPrice(200, 70, false)` → `"Квиток: 100 грн (знижка: пенсійна)"`
    • `calcTicketPrice(200, 22, true)` → `"Квиток: 140 грн (знижка: студентська)"`
    • `calcTicketPrice(undefined, 30, false)` → `"Квиток: 200 грн (знижка: відсутня)"`

Оператори та методи: `??`, `if/else if/else`, арифметика (`*`, `-`), template literals, `return` або `console.log`

Розклад сеансів — `printSchedule`

На сторінці кінотеатру відображається сітка сеансів на день. Функція будує розклад автоматично: кожен наступний сеанс починається одразу після закінчення попереднього.

Картина задачі словами:

Перший сеанс о `10:00`, фільм триває `105` хвилин. Значить другий — о `11:45`, третій — о `13:30` і так далі. Але після `23:00` нові сеанси не починаються. Функція виводить у консоль весь розклад і зупиняється, як тільки наступний сеанс виходить за межі дня.

Запитання для роздумів:

  • Як зберігати поточний час, якщо він вимірюється в хвилинах від початку доби? Що таке `10 * 60`?
  • Як після кожного сеансу зрушити час на тривалість фільму? Яка операція це робить?
  • Як з кількості хвилин отримати години та хвилини окремо — для виведення у форматі `"11:45"`? Що робити, якщо хвилин < 10?
  • Яка умова зупиняє цикл достроково? Який оператор використовується для виходу з циклу?
  • Що буде, якщо `sessionCount = 10`, але вже на 4-му сеансі час перейде за `23:00`? Скільки рядків виведеться?

Завдання:

  • Оголоси функцію `printSchedule(startHour, sessionCount, durationMinutes)` через function declaration.
  • Переведи `startHour` у хвилини від початку доби (`startHour * 60`).
  • У циклі `for` від `1` до `sessionCount` включно:
    • Обчисли час початку і кінця поточного сеансу.
    • Якщо час початку `>= 23 * 60` — зупини цикл через `break`.
    • Інакше — виведи рядок: `` `Сеанс ${i}: ${startH}:${startM} – ${endH}:${endM}` ``
    • Зрушити поточний час на `durationMinutes` для наступної ітерації.
  • Для форматування хвилин: якщо хвилин менше 10 — додай `"0"` спереду (напр. `"09"` замість `"9"`).
  • Виклич функцію:
    • `printSchedule(10, 5, 105)` — сеанси з 10:00, по 1 год 45 хв, максимум 5 шт.

Оператори та методи: `for`, `break`, `%`, `Math.floor()`, `if`, template literals, конкатенація рядків
