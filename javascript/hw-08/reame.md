# Домашнє завдання: Робота з DOM та Data-атрибутами (Фільтр ноутбуків)

## Вступна частина: Концепція

Ви створюєте інтерактивну вітрину для магазину ноутбуків. Замість того, щоб щоразу перевантажувати сторінку, ви реалізуєте миттєве фільтрування товарів за допомогою JavaScript, використовуючи стандартні методи DOM та `data-атрибути`.

---

## 1. Підготовка HTML-структури та Даних

Для роботи вам знадобиться статичний список з 12 ноутбуків у HTML та масив об'єктів для можливих розширень.

**Картина задачі словами:**
У вашому HTML-файлі має бути 12 карточок ноутбуків(достатньо назв, без зображень та без будь-якої додаткової структури та інфи). Кожна карточка — це елемент (наприклад, `div` або `li`), який містить `data-category` ("ігровий", "офісний", "ультрабук"). Також зверху мають бути 3 кнопки для фільтрації та кнопка "Показати всі".

**Запитання для роздумів:**
> - Як `data-атрибути` допомагають JS "розуміти", до якої категорії належить HTML-елемент?
> - Чому зручніше використовувати `className` або `classList` для приховування елементів, ніж напряму змінювати `style.display`?
> - Який селектор допоможе вибрати всі картки товарів одночасно?

**Ваше завдання:**
- Створіть HTML-сторінку з 12 картками ноутбуків.
- Додайте кожній картці атрибут `data-category` (розподіліть їх порівну між 3 категоріями).
- Створіть блок кнопок: `[Ігрові]`, `[Офісні]`, `[Ультрабуки]`, `[Всі]`.

---

## 2. Логіка вибору кнопок — Event Listeners

Щоб фільтр працював, нам потрібно навчити кнопки "слухати" кліки користувача.

**Картина задачі словами:**
Напишіть код, який знаходить всі кнопки фільтрації та додає кожній з них обробник події `click`. Коли ми тиснемо на кнопку, ми маємо дізнатися, яку саме категорію хоче бачити користувач.

**Запитання для роздумів:**
> - Як отримати значення `data-атрибута` з кнопки, на яку клікнули? 
> - Як виділити "активну" кнопку (змінити їй колір), щоб користувач бачив, який фільтр зараз діє?

**Ваше завдання:**
- Знайдіть кнопки в DOM.
- Додайте обробник події, який при кліку виводить у консоль категорію вибраного фільтра.

_Ключові слова: `addEventListener`, `event.target`, `dataset`_

---

## 3. Реалізація фільтрації — Маніпуляції з DOM

Це основна частина завдання: ми маємо показати потрібні товари та сховати інші.

**Картина задачі словами:**
Коли клікнули на "Ігрові", ми проходимо циклом по всіх 12 картках. Якщо категорія картки збігається з "ігровий" — ми її показуємо. Якщо ні — додаємо клас (наприклад, `.hidden`), який робить її невидимою. Якщо обрано "Всі" — знімаємо обмеження з усіх.

**Запитання для роздумів:**
> - Як метод `element.classList.toggle` або `add/remove` допоможе керувати видимістю?
> - Яка властивість CSS найкраще підходить для приховування (`display: none` чи `visibility: hidden`)?

**Ваше завдання:**
- Напишіть функцію фільтрації.
- При кліку на кнопку категорію:
  1. Пройдіть циклом `forEach` по всіх картках ноутбуків.
  2. Порівняйте `dataset.category` картки з категорією кнопки.
  3. Додайте/видаліть клас для приховування.

_Методи: `classList.add()`, `classList.remove()`, `forEach()`_

## 4. (Додатково) Робота з атрибутами об'єктів

**Ваше завдання:**
- Створіть масив з 12 об'єктів (бренд, ціна, категорія).
- Оформіть логіку так, щоб при наведенні (`mouseover`) на картку, її атрибут `title` отримував значення "Ціна: [ціна з об'єкта] грн".
- При виведенні мишки за межі картки (`mouseout`) атрибут `title` очищувався.

_Методи: `setAttribute()`, `removeAttribute()`, `mouseover/mouseout`_
