Домашнє завдання: Класи та робота з об'єктами (Магазин ноутбуків)

Вступна частина: Концепція

Ви працюєте розробником у магазині електроніки. Вам потрібно створити систему, яка автоматизує облік ноутбуків, що потрапляють у відділ уцінки (через дефекти, вітринні екземпляри або пошкоджену упаковку).

Початкові дані для роботи (База нових ноутбуків)

Для створення екземплярів уцінених товарів ви можете брати дані з цього масиву нових ноутбуків: 


    const newLaptopsBase = [
        { brand: "Apple", model: "MacBook Air M2", price: 48000 },
        { brand: "ASUS", model: "ROG Strix G15", price: 52000 },
        { brand: "Lenovo", model: "IdeaPad 3", price: 18500 },
        { brand: "HP", model: "Pavilion 15", price: 24000 },
        { brand: "Dell", model: "XPS 13", price: 65000 },
    ];

Проектування структури — Клас `DiscountedLaptop`

Перш ніж створювати конкретні товари, нам потрібен "шаблон" (креслення), за яким вони будуть будуватися.

Картина задачі словами:

Створіть клас, який описує ноутбук з уцінкою. Кожен такий ноутбук повинен мати свій бренд, модель, скільки він коштував спочатку, який відсоток знижки на нього діє, чому саме його уцінили та скільки таких одиниць залишилося.

Запитання для роздумів:

  • Які параметри має приймати конструктор (`constructor`) при створенні нового об'єкта?
  • Як правильно зберегти ці параметри всередині екземпляра класу?
  • Чи варто встановлювати кількість на складі (`quantity`) за замовчуванням, якщо вона не вказана?

Завдання:

  • Створіть клас `DiscountedLaptop`.
  • У конструкторі опишіть властивості: `brand`, `model`, `originalPrice`, `discountPercentage`, `discountReason` та `quantity`.
  • Створіть перший об'єкт, взявши дані для бренда, моделі та ціни з масиву `newLaptopsBase` (наприклад, перший елемент). Додайте причину уцінки та кількість самостійно.

Ключові слова: `class`, `constructor`, `this`, `new`

Логіка ціноутворення — `getFinalPrice` та `updateDiscount`

Товари з уцінкою часто потребують перегляду ціни: якщо товар довго не купують, знижка може зрости.

Картина задачі словами:

Нам потрібен метод, який не просто показує знижку, а вираховує реальну вартість ноутбука в гривнях прямо зараз. Також потрібна можливість "на льоту" змінювати відсоток уцінки.

Запитання для роздумів:

  • Як за допомогою формули вирахувати ціну зі знижкою? (Підказка: `originalPrice * (1 - discountPercentage / 100)`).
  • Чи повинен метод `getFinalPrice` змінювати оригінальну ціну в об'єкті, чи просто повертати результат обчислення?
  • Як метод `updateDiscount` має обробляти ситуацію, якщо передано від'ємне число або число більше 100? (За бажанням).

Завдання:

  • Додайте метод `getFinalPrice()`, який повертає кінцеву ціну.
  • Додайте метод `updateDiscount(newPercent)`, який оновлює властивість `discountPercentage`.
  • Перевірте роботу: виведіть ціну до оновлення знижки та після.

Методи: арифметика в JavaScript, `return`

Комерційні операції — `sell` та `addStock`

Товар приходить на склад і продається клієнтам. Система має стежити за залишками.

Картина задачі словами:

При продажі ми зменшуємо кількість товару. Але ми не можемо продати більше, ніж у нас є! Якщо хтось хоче купити 5 ноутбуків, а в наявності лише 2, система має про це чесно сказати.

Запитання для роздумів:

  • Яку умову (`if`) використати, щоб перевірити наявність товару перед продажем?
  • Як компактно вивести інформацію про товар у зручному вигляді для менеджера (метод `getInfo`)?
  • Що поверне метод `isAvailable()`, якщо `quantity` дорівнює 0?

Завдання:

  • Додайте метод `sell(amount)`: він зменшує кількість, якщо товару достатньо, або виводить повідомлення про дефіцит.
  • Додайте метод `addStock(amount)` для поповнення залишку.
  • Додайте метод `getInfo()`, який інформативно виводить: `"Ноутбук [Бренд] [Модель]. Причина уцінки: [Причина]. Ціна: [Сума] грн."`

Оператори: `if/else`, альтернативні оператори присвоєння `-=`, `+=`

(Додатково) Автоматизація та аналіз складу

Коли товарів багато, ми зазвичай тримаємо їх у масивах для зручної обробки.

Картина задачі словами:

Уявіть, що у вас є масив `discountInventory`, де лежать 5-6 різних ноутбуків. Напишіть код, який знаходить "найдешевший" ноутбук після уцінки або список тих, що є в наявності.

Запитання для роздумів:

  • Як поєднати методи масивів (`filter`, `map`) з методами класів?
  • Чи можна викликати `laptop.getFinalPrice()` всередині циклу `forEach`?

Завдання:

  • Створіть масив `discountInventory`, що містить 3-5 об'єктів класу `DiscountedLaptop` (використовуйте дані з `newLaptopsBase` для наповнення).
  • Використовуючи цикл або методи масивів, виведіть у консоль інформацію (`getInfo()`) лише про ті ноутбуки, які зараз є в наявності (`quantity > 0`).

Методи: `filter()`, `forEach()`, `this`
