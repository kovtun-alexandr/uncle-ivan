# Homework 09

## Робота з fetch

Базовий URL: https://akabab.github.io/superhero-api/api

Створи сторінку Superhero Cards, на якій будуть показані картки супергероїв, отримані через fetch.

### Кожна картка має містити:
- зображення героя;
- ім’я героя;
- справжнє ім’я, якщо воно є;
- видавництво / всесвіт;
- тип персонажа: good / bad / neutral;
- кілька характеристик сили:
  - intelligence;
  - strength;
  - speed;
  - power;
  - combat.

### При натисканні на картку потрібно показати більше інформації:
- зріст;
- вага;
- раса;
- місце народження;
- перша поява;
- рід занять;
- групова приналежність.

### Додатково:
- пошук за героями;
- сортування від a-z і z-a.
